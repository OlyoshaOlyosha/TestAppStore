# TestAppStore - Учебный проект

## Описание

Проект представляет собой консольное приложение для работы с базой данных пользователей. Создан в рамках изучения взаимодействия Java с реляционными базами данных, выполнения SQL-запросов и базового шифрования данных.

## Изученные концепции

- Работа с реляционными базами данных через JDBC
- Использование паттерна проектирования (интерфейс + реализация)
- Базовое шифрование данных с помощью Base64
- Выполнение SQL-запросов (SELECT, INSERT)
- Организация подключения к PostgreSQL
- Работа с подготовленными выражениями (PreparedStatement)
- Обработка исключений при работе с БД

## Что реализовано

- Подключение к базе данных PostgreSQL и выполнение запросов
- Шифрование паролей пользователей перед сохранением в БД
- Добавление новых пользователей и просмотр существующих
- Дополнительные утилиты: транслитерация кириллицы и приветствие по времени суток

## Технологии

- Язык: Java 20
- База данных: PostgreSQL
- Сборка: Maven
- Библиотеки: PostgreSQL JDBC Driver

## Примечание

Проект создан в учебных целях для демонстрации базовых навыков работы с базами данных.
